# LAN Topologies Overview

A simple single-page website that explains different types of local network topologies. It features an interactive gallery, comparison tables, and a contact form. Built with Vue 3 and Bootstrap 5.

## What's Inside

- **Overview & Types:** Explanations of common network setups—Bus, Star, Ring, Mesh, and Tree.
- **Comparison Table:** Quick breakdown of the pros, cons, and use cases for each topology.
- **Interactive Gallery:** Includes full-size view with manual navigation, thumbnails, and an automatic 5-second slideshow timer.
- **Contact Form:** Basic form with basic client-side validation for user input.
- **Responsive Layout:** Works on both mobile and desktop screens.

## Tech Stack

- **Vue 3** (via CDN, using Composition API)
- **Bootstrap 5** (CSS framework)
- HTML & CSS

## How to Run

No build step or Node.js environment is required.

1. Download or clone this repository.
2. Make sure all diagram images are in the same folder as `lab4.html`:
   - `Bus_topology.png`
   - `Star_topology.png`
   - `Ring_topology.png`
   - `Full_topology.png`
   - `Tree_tech.png`
3. Double-click `lab4.html` to open it in any web browser (or run it via VS Code's Live Server).
